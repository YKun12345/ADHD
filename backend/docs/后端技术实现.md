# 后端技术实现

> 智绘脑图（SmartBrainMap）· ADHD 智慧辅助诊断平台 —— 后端工程说明。整理后端技术选型、架构、核心模块与关键实现，供竞赛报告/答辩素材使用。

## 一、技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| Web 框架 | FastAPI | 自动生成 `/docs` 与 `/openapi.json` |
| ORM | SQLAlchemy 2.x | 声明式模型 + `Base.metadata.create_all` 建表 |
| 数据校验 | Pydantic | 请求/响应 Schema |
| 鉴权 | OAuth2 + JWT | `Authorization: Bearer <token>` |
| 数据库 | SQLite（开发）→ MySQL（生产） | 由 `DATABASE_URL` 一键切换 |
| 密码策略 | 自定义规则 | `core/password_policy.py` |
| AI 大模型 | 通义千问（Qwen） | 无 key 时降级为本地启发式模板 |
| 影像推理 | HGST（GNN 时序） | torch+dhg，缺失时由 mock 兜底 |
| 静态资源 | `StaticFiles` 挂载项目根 | 纯静态 H5 与 API 同源同端口 |

## 二、目录结构

```text
backend/
├── main.py                     # 应用入口：CORS、路由挂载、静态文件、findviz WSGI
├── create_tables.py             # 一次性建表脚本
├── app/
│   ├── api/
│   │   ├── router.py           # 聚合 9 个子路由
│   │   └── routes/            # auth/patient/ai/ai_enhanced/care/doctor/model_inference/security/health
│   ├── models/                # 12 张表模型
│   ├── schemas/               # 请求/响应 Schema 模块
│   ├── services/              # 业务服务（算分/自适应/异常检测/多模态/智能看板…）
│   ├── core/                  # config（配置）/security（令牌）/password_policy
│   └── db/                    # base / session / init_db
├── sql/init_mysql.sql         # MySQL 建表 DDL
├── scripts/seed_demo_data.py  # 演示数据一键生成
└── docs/                      # 本文档 + 内网访问方案
```

## 三、数据库设计

- 使用 SQLAlchemy ORM，`db/init_db.py` 在应用 `startup` 时执行 `create_all`，实现「零迁移、启动即建表」。
- 核心表及关系：

| 模型 | 表 | 说明 |
|---|---|---|
| User | `users` | 账号，role = patient / researcher / dac |
| Patient | `patients` | 患者档案（user 1:1，patient_type 成人/儿童） |
| ScaleResult | `scale_results` | 量表结果（ASRS/SNAP-IV 总分、风险分级、雷达五维） |
| CognitiveTest | `cognitive_tests` | 认知测试（reaction/stroop/trail/flanker/nback/digit） |
| TrackingLog | `tracking_logs` | 每日行为日志（14 天，同天 upsert） |
| ImagingVisualization | `imaging_visualizations` | 影像可视化（nifti/gifti） |
| ModelPrediction | `model_predictions` | 模型预测（ADHD 二分类 + 概率） |
| CareMessage / PatientTask | — | 医患关怀消息 / 任务 |
| AiChatLog | `ai_chat_logs` | AI 对话日志 |
| Upload | `uploads` | 文件上传元数据 |
| Security 相关表 | `security.py` | DAC / PDP-PoR 审计 |

- 双模式：`DATABASE_URL` 为空 → 拼 MySQL URI（`mysql+pymysql://...`）；`sqlite:///./backend/app.db` → SQLite。`sql/init_mysql.sql` 提供等价 MySQL DDL。

## 四、认证与鉴权

- `POST /api/v1/auth/login`：入参 `identifier`（邮箱/用户名）+ `password` + `role`，返回 JWT `access_token` + `token_type=bearer` + `user`。
- `core/security.py`：`create_access_token`（HS256，默认 1440 分钟）/ `get_current_user` 依赖注入。
- 患者接口通过 token 的 `sub`（user id）关联 `patient_id`。
- 密码策略在 `core/password_policy.py`（含复杂度校验）。

## 五、核心业务实现

### 1. 量表算分（`routes/patient.py`）
- `POST /patient/submit_scale`：ASRS（成人 18 题）、SNAP-IV（儿童 26 题），返回 `total_score` / `risk_level`（低/中/高）/ `radar_scores`（注意/冲动/多动/认知/情绪五维）/ 分维度 `sub_scores` / `summary` / `recommendations`。

### 2. 认知测试（`routes/patient.py`）
- `POST /patient/submit_cognitive_test`：多 `test_type`（reaction/stroop/trail/flanker/nback/digit），原始结果统一入 `result_json`。

### 3. 每日日志与趋势（`routes/patient.py`）
- `POST /patient/submit_daily_log`：记录 focus_minutes + 5 项 rating + 情绪，同天重复提交为 upsert。
- `GET /patient/dashboard_status`：返回 `logs`（逐日 focus_minutes + 5 项 rating + day_index，可绘 14 天折线）+ `tracking_summary`（平均专注/平均情绪/完成度）。

### 4. 综合报告（`routes/patient.py`）
- `GET /patient/comprehensive_report`：聚合五维 —— 资料 / 量表 / 认知 `radar_scores` / 追踪 `tracking_summary` / 影像+模型预测。

### 5. AI 助手（`routes/ai.py` + `services/*`）
- `POST /ai/chat`、`/ai/explain_report`、`/ai/generate_reminder`。
- Qwen 接入时走 provider；无 `QWEN_API_KEY` 时降级为 `heuristic_*` 模板（`degraded=true`，`model=fallback-template`），前端始终可用。
- 增强服务（`services/`）：自适应评估、异常检测、多模态分析、干预方案、智能看板、自然语言查询、个性化提醒等。

### 6. 影像预测（`routes/model_inference.py`）
- `POST /model/predict_fmri`：真实 HGST（GNN 时序）预测，依赖 torch+dhg；环境缺失时返回 503。
- `POST /model/predict_mock`：基于 (patient_id, file_name) 的 sha256 生成确定性 ADHD 概率（0.60~0.90），写 `model_predictions`（source_type=mock），保证演示可复现。

## 六、安全体系（`routes/security.py` + `services/security_service.py`）

- DAC（数据访问控制）审计：`/security/dac/*`（audit_logs / patients / recent_audits / spatial_audits / temporal_audits）。
- PDP/PoR 数据外包完整性审计拦截器：预留加密审计能力。
- 分层权限：patient / researcher / dac 三种角色按接口隔离。

## 七、CORS 与部署

- `main.py` 的 CORS `allow_origin_regex` 放行 `localhost` / `127.0.0.1` 及私有网段（10.x、172.16~31.x、192.168.x.x）任意端口。
- 后端默认可绑 `0.0.0.0:8000` 供局域网/真机访问（详见 `docs/内网访问方案.md`）。
- 静态 H5、`/docs`、`/openapi.json` 均由 8000 端口统一提供。

## 八、启动方式

```bash
# 项目根目录
.venv\Scripts\python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

启动后：页面 `http://127.0.0.1:8000/login.html`；接口文档 `http://127.0.0.1:8000/docs`。
