# 内网访问方案（小程序真机预览 / 局域网演示 / 公网穿透）

> 适用于「智绘脑图 SmartBrainMap」平台的联调与演示场景。
> 后端为 FastAPI，静态页面（`login.html`、`patient_*.html` 等）与 API 均由同一个 8000 端口服务；数据库默认 SQLite（`backend/app.db`）。

---

## 一、先决条件：后端必须绑定 `0.0.0.0`

只有绑定 `0.0.0.0`，手机/其他电脑才能通过局域网 IP 访问到后端。绑定 `127.0.0.1` 时只能本机访问。

```bash
# 项目根目录
.venv\Scripts\python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

看到 `Uvicorn running on http://0.0.0.0:8000` 即成功。

> ⚠️ 项目自带的 `.claude\start.bat` 默认绑定 `127.0.0.1`（仅本机）。如需局域网/真机访问，请按上文命令**手动以 `--host 0.0.0.0` 启动**。

**CORS 已内置放行**：`backend/app/main.py` 的正则已允许 `localhost`/`127.0.0.1` 及私有网段（`10.x`、`172.16~31.x`、`192.168.x.x`）任意端口的跨域来源，局域网访问不会触发跨域拦截。

## 二、方案 A：手机热点 / 同一局域网（免公网，推荐用于真机联调）

适用：手机与电脑连到**同一个 WiFi**，或电脑连手机开的热点。

1. 获取电脑在局域网中的 IP：
   ```bash
   ipconfig
   ```
   找到类似 `192.168.x.x` 的「无线局域网适配器 WLAN」IPv4 地址。

2. 手机/小程序把后端地址指向 `http://<电脑IP>:8000`，例如：
   ```
   http://192.168.1.50:8000/login.html
   ```
   在手机浏览器里直接打开这个地址，能加载页面即代表网络通了。

3. 前端静态页（H5 内嵌）已通过 CORS 校验，无需额外配置；小程序需另行设置（见第四节）。

### 局限
- 必须同一局域网，物理距离受限。
- 无法在公网环境（如异地演示、评委远程访问）使用。

---

## 三、方案 B：ngrok 内网穿透（公网访问，无需固定公网 IP）

适用：需要公网可访问（远程评审、演示）、或小程序要求 HTTPS 合法域名时。

1. 到 [ngrok 官网](https://ngrok.com/) 注册账号并下载 ngrok，或使用国内穿透工具（如 [cpolar](https://www.cpolar.com/)、[natapp](https://natapp.cn/) 等）。

2. 本机先启动后端（`--host 0.0.0.0` 或 `127.0.0.1` 均可，ngrok 会转发本地 `127.0.0.1:8000`）：
   ```bash
   .venv\Scripts\python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
   ```

3. 另开一个终端启动隧道：
   ```bash
   ngrok http 8000
   ```
   终端会显示一个公网地址，形如 `https://xxxx.ngrok-free.app`。

4. 外部即可通过该公网地址访问后端，例如：
   ```
   https://xxxx.ngrok-free.app/login.html
   ```

### 说明
- ngrok 免费版地址每次重启会变化；付费版可用自定义固定地址。
- ngrok 默认给的是 `https`，满足小程序「合法域名须为 HTTPS」要求（但免费子域名每次变化，需重新配置，见第四节）。

## 四、小程序真机预览配置

小程序项目位于 `miniprogram/`，当前 AppID 为 `wx5fc79e35c64730d9`。

### 4.1 开发阶段「不校验合法域名」方式（最快）

微信开发者工具中：

1. 「详情」→「本地设置」→ 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**。
2. 在同一网络下，可将后端地址设为 `http://<电脑IP>:8000`，或使用 ngrok 的 `https` 地址。
3. 「预览」生成二维码，用手机微信扫码即可真机预览。

> 真机预览时该开关同样生效，但仅限开发者本人的微信；其他体验者需加入「体验成员」或走正式发布流程。

### 4.2 正式/分享发布（需合法 HTTPS 域名）

1. 后端需暴露在 HTTPS 域名下（ngrok 付费固定域名，或部署到自有服务器并绑定域名 + TLS 证书）。
2. 在「微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名」中，把该 HTTPS 域名加入 **request 合法域名**。
3. 小程序代码内将 request 的 base URL 指向该域名（当前 base URL 尚未写入代码，登录页为脚手架，待接入时在 `utils` 新增配置即可，见下述注意事项）。

### 注意事项
- 微信小程序 request 只允许 HTTPS，且域名须加入 request 合法域名白名单。
- 当前 `miniprogram/` 为脚手架（仅登录/首页两页），尚未接后端；接后端时需在 `utils/` 增加 base URL 配置，统一从 `app.js` 或 `utils/config.js` 读取，指向上述 HTTPS 域名。
- 后端 CORS 的 `allow_origin_regex` 目前只放行 http/localhost 及私有网段；若小程序通过 HTTPS 合法域名（公网）请求，则需要在 `allow_origins` 或正则后追加该域名（届时按联调结果更新）。

## 五、两种方案对比与选择建议

| 维度 | 方案 A（热点/局域网） | 方案 B（ngrok 公网） |
|---|---|---|
| 网络要求 | 手机与电脑同网 | 无需同网，有公网域名即可 |
| 成本 | 免费 | 免费（变动域名）/付费（固定域名） |
| 真机预览 | 开发者本人可 | 开发者本人可 |
| 正式发布 | 不满足 | 满足（付费固定域名 + 合法域名备案） |
| 典型用途 | 开发期真机联调 | 演示、远程评审、正式发布 |

**建议**：开发期联调优先用方案 A（快、免费、稳定）；需要异地演示或正式发布时再用方案 B。
