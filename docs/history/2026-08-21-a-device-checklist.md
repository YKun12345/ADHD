## 二、启动电脑后端

1. 在 PowerShell 中进入源码目录：

```powershell
Set-Location -LiteralPath '<AB合并版根目录>'
```

2. 使用项目虚拟环境启动后端，并允许局域网设备访问：

```powershell
python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

3. 保持这个 PowerShell 窗口运行，不要关闭。

4. 另开一个 PowerShell 窗口检查健康接口。命令中只填写普通 URL，不要复制 Markdown 方括号：

```powershell
Invoke-RestMethod -Method Get -Uri 'http://127.0.0.1:8000/api/v1/health'
```

- [ ] PowerShell 显示 `status` 为 `ok`。
- [ ] 后端窗口没有启动失败、数据库异常或持续报错。

## 三、查找电脑局域网 IPv4

1. 在 PowerShell 执行：

```powershell
ipconfig
```

2. 找到当前正在使用的“无线局域网适配器 WLAN”下的 IPv4 地址，例如 `192.168.1.8`。

3. 不要选择：

- `127.0.0.1`；
- 断开连接的网卡；
- VMware、Hyper-V、WSL 等虚拟网卡；
- 以 `169.254` 开头的自动分配地址。

记录：

```text
电脑局域网 IPv4：
准备填写的地址：http://________________:8000/api/v1
```

- [ ] 手机和电脑连接同一个 Wi-Fi。
- [ ] Windows 防火墙只对“专用网络”允许 Python/8000 端口访问。
- [ ] 路由器或手机热点没有开启设备隔离。

## 四、在小程序中设置服务器

1. 打开微信开发者工具并编译小程序。
2. 在登录页点击“服务器连接设置”。
3. 输入上面记录的地址，例如：

```text
http://192.168.1.8:8000/api/v1
```

4. 点击“测试连接并保存”。

- [ ] 页面显示“局域网调试”。
- [ ] 页面显示“连接成功，服务器地址已保存”。
- [ ] 关闭并重新进入设置页后地址仍然正确。
- [ ] 快速连续点击按钮时只发送一次健康检查请求。
- [ ] 输入错误地址时不会覆盖之前已经保存的地址。
- [ ] 点击“恢复开发者工具默认地址”后恢复为 `127.0.0.1`。
- [ ] 为真机测试重新保存电脑局域网地址。

## 八、常见故障定位

### “无法连接服务器”

按顺序检查：后端是否仍在运行、健康接口是否为 `ok`、是否使用电脑局域网 IPv4、是否同一 Wi-Fi、防火墙是否允许专用网络、路由器是否隔离设备。

### 开发者工具能连接，手机不能连接

最常见原因是仍使用 `127.0.0.1`。真机必须填写电脑局域网 IPv4；`127.0.0.1` 在手机上代表手机自身。

### 地址测试成功但业务请求出现 401

健康检查不需要 token，而业务请求需要登录。返回登录页重新登录，不要手工伪造或粘贴 token。

### Wi-Fi 变化后突然无法连接

电脑的局域网 IPv4 可能变化。重新执行 `ipconfig`，再到服务器设置页更新地址。
