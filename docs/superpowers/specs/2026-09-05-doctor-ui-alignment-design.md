# 医生端界面对齐修复设计

## 目标

修复医生端两页的三个纯界面问题，不改变数据请求、患者绑定、任务下发、消息发送或退出登录的业务行为。

## 改动范围

### 医生首页

- 顶部导航仅显示“医生工作台”，不再显示“退出”。
- “绑定患者”表单显式使用完整可用宽度、边框盒模型和内容裁切，避免表单或输入控件在页面左侧产生白色残块。
- 在页面内容末尾、“账号与隐私”入口下方增加“退出登录”按钮。
- 新按钮继续调用现有 `logout` 方法，退出后的会话清理和返回登录页行为保持不变。

### 患者随访页

- “下发任务”和“发送消息”按钮采用同一宽度、最小高度和居中规则。
- 不改变两个表单的字段、校验和提交逻辑。

## 实现策略

仅修改医生端页面的 WXML/WXSS，并补充页面结构回归测试。避免修改全局样式或公共导航组件，以免影响患者端及其他页面。

## 验收标准

1. 医生首页左边不再出现两个多余白色方块。
2. “下发任务”和“发送消息”按钮宽度一致，左右边界上下对齐。
3. 医生首页顶部不显示“退出”。
4. 医生首页最底部在“账号与隐私”下方显示“退出登录”。
5. 点击底部退出按钮仍清理会话并返回登录页。
6. 医生端现有自动化测试与新增回归测试全部通过。

## 非目标

- 不重做医生端视觉风格。
- 不调整患者卡片、统计卡片或随访表单的业务内容。
- 不修改患者端页面和公共导航组件的外观。
