# 微信小程序 A 端独立开发总设计

日期：2026-08-21

## 1. 目标与授权依据

本设计依据用户提供的《adhd智慧辅助诊断平台.pdf》《完善分工.pdf》以及用户“B 尚未开始、只完成 A 的工作、无需用户持续操作”的明确要求制定。

A 的目标是交付可在微信开发者工具运行、最终可扫码演示的患者端原生小程序，形成以下闭环：

```text
登录/注册 → 患者首页 → 行为量表 → 认知测试
→ 14 天追踪 → 综合报告 → AI/临床路径/科普
```

## 2. 严格范围边界

允许修改：

- `miniprogram/` 全部 A 端源码、测试与小程序配置；
- `docs/superpowers/specs/`、`docs/superpowers/plans/` 中 A 端设计和计划；
- `项目任务与进度.md` 中的进度、证据、风险和工作日志。

禁止修改：

- `backend/` 中的 FastAPI、数据库、鉴权、业务接口和部署代码；
- `doctor_*.html`、医生端脚本和 B 的 Web 联调成果；
- MySQL、服务部署、内网穿透、API 文档和作品报告 PDF；
- B 负责的演示数据、模型上传与预测接口。

A 可以只读查看 B 的现有接口和 schema，用于确定请求字段，但不能修复、补写或提交 B 的代码。

## 3. 实现方案比较

### 方案 A：等待 B 的真实接口再开发

优点是数据来源统一；缺点是 B 未工作时 A 完全阻塞，不符合当前要求。

### 方案 B：全部写死为本地演示数据

优点是开发快；缺点是以后接真实接口需要重写，容易把模拟结果误当真实结果。

### 方案 C：接口契约优先，并提供明确的 A 端降级数据（采用）

页面控制器始终面向稳定的数据转换模块。真实接口可用时调用现有 FastAPI 契约；接口缺失或离线时，只使用带来源标识的本地演示状态。纯数据转换、计分、进度计算和导航均可用 Node 自动测试覆盖。

## 4. 架构与数据流

每个业务模块拆成三层：

1. `utils/` 纯逻辑：题库、校验、计分、接口数据转换、本地状态转换；不直接访问 `wx`。
2. `pages/` 控制器：读取 storage、调用 `request`、调用纯逻辑、更新页面状态和执行导航。
3. WXML/WXSS：只负责展示和交互绑定，不在模板中实现业务判断。

标准数据流：

```text
用户操作 → 页面控制器 → 纯逻辑校验/转换
→ 真实接口（可用时）或本地演示状态（离线时）
→ 标准页面状态 → WXML 展示
```

模拟数据必须满足：

- 明确标为本地演示或待同步；
- 不伪造 HTTP 成功响应；
- 不写入真实 token；
- 将来接入 B 的接口时只替换数据来源，不重写页面核心逻辑。

## 6. 测试和提交规范

每个功能都执行：

```text
写失败测试 → 确认因缺少功能而失败 → 最小实现
→ 当前测试通过 → 全量回归 → 语法检查 → git diff --check
→ 精确暂存 → 独立提交 → 更新进度和工作日志
```

测试至少覆盖：

- 正常值、边界值、空值和非法值；
- 接口成功、离线、超时、异常结构；
- 重复点击、页面重复进入和本地状态恢复；
- 成人与儿童分支；
- 敏感信息不进入日志和持久化演示数据。

禁止使用 `git reset --hard`、`git checkout --` 或删除用户已有改动。禁止把 `.env`、本地数据库、真实 token 和真实口令提交到 Git。

## 7. D3 患者首页设计

D3 使用独立的 `home-dashboard` 纯逻辑模块统一处理真实接口和本地默认状态。页面在 `onShow` 刷新，使从量表、测试或追踪页返回后进度能够更新。

首页状态包括：患者姓名、当前天数、已完成天数、百分比、数据来源、加载状态、今日任务和快捷入口。无后端时显示“本地计划”，不显示错误弹窗打断用户；真实接口异常但已有本地状态时保留可用页面，并给出轻量提示。

导航采用明确路由表。已实现页面才能跳转；未实现入口显示不可用状态，不伪造成功页面。随着 D4—D12 完成，逐项启用对应路由。

## 8. 自审结果

- 无 `TBD`、`TODO` 或未定义占位功能；
- A/B 边界与两份 PDF 一致；
- 没有承诺替 B 编写接口；
- 离线数据与真实接口结果能够区分；
- 每个阶段都有测试、验收、提交和记录要求；
- 医疗结论继续保留“仅用于辅助筛查，不替代专业医生诊断”。
