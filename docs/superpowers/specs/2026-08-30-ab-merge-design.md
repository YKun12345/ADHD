- 新增契约测试和跨端烟测，任何未映射接口均不得标记完成。

### 阶段 4：关键功能补齐

## 9. 必须解决的已知缺陷

### 9.1 七类认知任务不完整

B 的综合报告当前只识别六类结果，A 新增的 `simple_reaction` 可能被忽略。合并版必须统一任务枚举、提交结构、数据库字段、报告聚合和 UI 展示。

### 9.2 上传与模型链路不真实完整

B 已有上传表但链路未完整使用，Mock 结果主要依赖文件名；医生端真实模型调用在缺少 `torch/dhg` 时会返回 503。合并版必须区分：

- 真实推理：依赖齐全、文件校验、状态跟踪、错误可见。
- 演示模式：显式标注 Mock，结果不可当作真实医疗结论。

### 9.3 演示数据不可重复加载

现有种子数据第二次执行可能因追踪日志唯一键失败。合并版要求重复运行不报错、不重复膨胀，并对创建、更新、跳过分别给出摘要。

### 9.4 报告字段兼容问题

旧认知种子结构与当前报告字段不完全一致，会产生空值或异常低值。必须通过迁移/适配消除，而不是只在页面隐藏。

### 9.5 环境不可移植

B 的虚拟环境保存了旧机器绝对路径。合并版只能提供从依赖清单创建新环境的方式，并同时给出 SQLite 快速启动与 MySQL 配置说明。

这些事项可记录为后续优化，但不能混入本次同步造成范围失控。
