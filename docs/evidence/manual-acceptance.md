## V3 重点人工场景

- [ ] 患者与医生账号首次登录分别显示一屏总引导；同账号同角色不重复，换账号互不继承，设置页可以重看。
- [ ] 页面气泡约 300ms 后出现、约 6 秒后收起；关闭自动介绍后不再自动出现，但星仔仍可手动打开帮助。
- [ ] 七项认知任务在说明、休息、结果阶段可显示助手，刺激、作答、数字播放、计时和提交/重试期间不显示。
- [ ] 患者消息首页只显示未读数字、不显示敏感正文；回复失败可重试，紧急提示清晰可见。
- [ ] 医生下发四类任务后，患者端显示截止日期和待完成/已完成/已过期状态，点击只跳转白名单页面，完成状态能回传。
- [ ] 专业评估结果默认折叠；患者端和医生端只读摘要均显示模型、版本、时间、来源和“不可独立用于诊断”说明。
- [ ] Stroop、Flanker、2-back 各 24 试次，连线约 24 节点，数字广度满足失败条件后提前结束；页面、结果和协议元数据一致。
- [ ] 每日追踪默认只显示快速记录，详细记录可展开且保存/恢复完整；输入期间星仔不弹出。
- [ ] 医生工作台姓名搜索、风险/完成筛选、待办、未读消息、近期摘要、AI 对话摘要和影像只读摘要在小屏幕可用。

- [ ] 服务器设置能保存、探测并切换到正确的 `/api/v1` 地址。
- [ ] 患者演示账号完成登录、注册错误提示和会话退出。
- [ ] ASRS/SNAP-IV、七类认知任务、追踪、报告、关怀路径、科普和 AI 页面逐项可进入。

## 模型和医疗边界

- [ ] 演示 Mock 在页面、接口响应和导出内容中始终有醒目标识与免责声明。
