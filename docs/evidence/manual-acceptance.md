# AB 合并版人工验收清单

状态：以下项目均为待人工/外部环境验收。自动测试不能代替本清单，也不能证明医学有效性或生产合规性。

## 微信开发者工具

- [ ] 以 `miniprogram/project.config.json` 导入项目并无错误完成编译。
- [ ] 服务器设置能保存、探测并切换到正确的 `/api/v1` 地址。
- [ ] 患者演示账号完成登录、注册错误提示和会话退出。
- [ ] ASRS/SNAP-IV、七类认知任务、追踪、报告、关怀路径、科普和 AI 页面逐项可进入。
- [ ] 网络失败、401、后端不可用时有可理解提示，不泄露口令或患者资料。

## Android 与 iOS 真机

- [ ] 各完成一次同一可信局域网联调，记录手机型号、系统、微信和基础库版本。
- [ ] 两端分别验证登录、量表、七类认知任务、追踪和报告完整流程。
- [ ] 检查安全区域、键盘遮挡、滚动、触控目标、横竖屏和弱网恢复。
- [ ] 正式候选版本使用已备案 HTTPS/request 合法域名，不依赖“关闭域名校验”。

## 医生 / 研究人员 Web

- [ ] 通过 `/doctor-web/` 登录，不使用 `file://` 或归档患者网页。
- [ ] 完成患者列表、患者综合报告、影像上传、影像可视化和医生任务下发。
- [ ] 下发的量表、认知、追踪、报告任务在小程序中解析为正确页面。
- [ ] DAC 账号权限、审计记录和越权拒绝由项目负责人复核。

## 模型和医疗边界

- [ ] 演示 Mock 在页面、接口响应和导出内容中始终有醒目标识与免责声明。
- [ ] 真实 HGST 环境安装指定依赖，加载批准的权重/标签并完成独立数据验证。
- [ ] 缺少真实依赖、权重或输入不合法时返回错误，不静默生成 Mock 结果。
- [ ] 医学阈值、敏感性/特异性、适用人群和报告措辞由有资质人员审核。

## 安全与发布

- [ ] 替换生产 `SECRET_KEY`、数据库口令和第三方 API 密钥，并使用密钥管理系统。
- [ ] 不使用真实患者数据做开发演示；上传、日志、备份和删除策略通过隐私审查。
- [ ] 完成 HTTPS、域名备案、数据库备份恢复、访问控制、依赖漏洞和审计日志检查。
- [ ] 项目负责人签署版本号、提交号、验收日期、未解决缺陷和回滚方案。
