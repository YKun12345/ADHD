# 主系统统一使用指南

本轮已把三个示例账号和预填数据接入原8000后端。日常使用一个系统、一套主数据库；示例账号和正常注册账号使用相同页面及业务接口。旧8770资料保留作独立备份，不需要切过去。

## 启动和登录

双击桌面“知行合医-启动后端8000”，或按 **Ctrl+Alt+B**，也可双击项目根目录“启动后端.cmd”。原“启动竞赛演示.cmd”已改为同样启动8000；不重新生成数据。后端同时运行提交状态处理和星仔任务恢复。

- 用户网页：http://127.0.0.1:8000/patient-web/login.html
- 医生网页：http://127.0.0.1:8000/doctor-web/login.html
- 电脑微信开发者工具的小程序服务器地址：**http://127.0.0.1:8000/api/v1**。

若此前手动设为8770，请在小程序登录页“服务器设置”改回上面的8000一次，然后重新登录。没有自动清除微信存储或未发送队列。

## 新评估如何使用

用户从“评估”新建一轮；医生从具体共享档案新建并发布。背景资料可以跳过，随后确认实际填写者/执行者，逐项完成量表和认知任务。真实提交、失败恢复、状态更新仍使用原协议与版本校验。自助评估完成后进入自助结果；医生安排的评估提交后进入医生待办，医生核对并明确发布意见和计划，用户读取并记录。

现在8000开发主后端可运行参考评估，不再要求APP_ENV=test。参考用途与临床诊断资格分开；没有把既有模板、来源、机构核验标成专业批准。原冻结题目、计分配置、模板摘要和历史回执保持兼容。

## cpolar

现有业务隧道继续指向 **127.0.0.1:8000**，无需为示例账号切换端口。将Cpolar Web UI在线列表里的当前HTTPS域名加上 `/patient-web/login.html` 或 `/doctor-web/login.html` 即为两端网页；手机小程序使用该HTTPS域名加 `/api/v1`。9200仍仅为cpolar管理页面。

本轮没有更改或启停公网隧道、没有取得当前域名或验证公网/真机可达性。也没有进行训练、真实微信投递、外部AI调用或发布。

## 保存与恢复

新增账号和预填数据已保存于主库，不随关闭或重启服务消失。备份包含原主SQLite、独立授权账本、原密钥和配置，位于 `.codex-tmp/main-examples/backups/`。不要将旧业务库单独覆盖回当前库或单独回滚授权账本；需要回退时先停服务并核对备份一致性，避免丢掉后来新建的资料。

执行结果与真实验证见 `docs/evidence/main-system-2026-10-18/`。十图方案依旧是9张小程序和1张影像网页，但使用本指南8000的档案编号。
