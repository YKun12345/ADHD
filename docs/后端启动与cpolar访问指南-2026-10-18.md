## 1. 最方便的启动方法

桌面已经新增两个快捷方式，也设置了Windows快捷键：

| 桌面快捷方式 | 快捷键 | 使用哪套数据 |
| --- | --- | --- |
| 知行合医-启动后端8000 | Ctrl+Alt+B | 原项目后端、原账号和资料 |
| 知行合医-启动竞赛演示8770 | Ctrl+Alt+D | 林医生、小禾、小安及已准备的独立合成数据 |

双击或者按快捷键均可。当前想看带数据的竞赛演示，使用 **Ctrl+Alt+D**。启动窗口显示已经运行或启动成功后可以关闭，服务继续在后台运行。重复启动复用现有服务，不会重建已有演示数据，不结束不明占用进程。

项目根目录也有 `启动后端.cmd`、`启动竞赛演示.cmd`，项目被整体移动或桌面快捷方式丢失时可从这里启动。重新创建快捷方式可运行 `tools/install-start-shortcuts.ps1`；它不覆盖不属于本项目的同名快捷方式，已占用的快捷键会保留。

两个双击入口已用Windows自带PowerShell实际运行，均正确识别已有服务。发现并修复了PowerShell5对无charset JSON的中文目录解码问题；修后仍指向原合成实例，不重新注册账号。桌面快捷键已通过快捷方式属性读回核对，未模拟实际键盘按键。

## 3. 沿用你的Cpolar Web UI

管理页面：**http://127.0.0.1:9200/** 。cpolar当前已有进程运行，管理页面返回200。只读核对到配置中的 `adhd-backend` 隧道为HTTP，本地地址 **127.0.0.1:8000**。本轮没有修改、创建或启停任何公网隧道。

需要通过公网访问时，先启动对应本机服务，再在cpolar中操作：

1. 登录9200管理页，进入“隧道管理 → 隧道列表”。
2. 找到 `adhd-backend`，查看或编辑其本地地址。继续用原资料就保持 `127.0.0.1:8000`。若决定对外演示刚准备的小安、小禾合成数据，需要将目标设为 `127.0.0.1:8770`，或者为8770另建一条HTTP隧道；保留哪条由你在界面明确选择，不会自动替换。
3. 保存后进入“状态 → 在线隧道列表”，复制当前 **HTTPS公网地址**。9200是cpolar管理端口，不是作品后端地址；不把业务隧道指向9200。
4. 用复制到的域名替换下面的“当前HTTPS公网域名”。不沿用可能已变化的旧域名。

| 用途 | 公网地址组成 |
| --- | --- |
| 用户网页 | 当前HTTPS公网域名 + `/patient-web/login.html` |
| 医生网页 | 当前HTTPS公网域名 + `/doctor-web/login.html` |
| 手机小程序服务器设置 | 当前HTTPS公网域名 + `/api/v1` |

网页从公网域名打开后会使用同源API，不必另外配置浏览器前端地址。手机不能用127.0.0.1访问电脑；127.0.0.1仅适用于这台电脑本机的浏览器和微信开发者工具。

cpolar界面操作依据：[官方文档](https://www.cpolar.com/docs)、[编辑隧道说明](https://www.cpolar.com/blog/how-to-edit-and-modify-the-tunnel-created-by-cpolar-intranet-penetration)。本轮没有取得登录后的当前在线域名，也没有把历史日志或配置名当作当前公网访问成功；域名和对外可达性以你在Web UI读取及实际访问的结果为准。

## 4. 常见现象

- **本机网页也打不开**：先双击对应启动入口，看是否启动成功；8000、8770分别检查。
- **本机正常，公网打不开**：在cpolar检查隧道在线、本地目标端口与所启动的服务一致，并使用当前在线域名。
- **演示账号登录失败**：先核对是不是连到了8000；本次演示账号应连8770或映射8770的公网域名。
- **网页只显示后端欢迎信息**：在网址后加上用户或医生的完整登录页路径。
- **微信工具再出现MaxCodeSize错误**：运行 `tools/open-competition-miniprogram.ps1` 使用已验证的项目窗口入口；见演示指南第七节。

正式小程序上线、实际公网投递及目标环境验收仍按已有授权范围另行执行。本轮仅交付本机启动入口、快捷键和cpolar使用说明。
