HGST 模型训练流程

Hypergraph Self-supervised Transformer · 脑功能影像 ADHD 二分类
模型定位：为平台提供客观分析能力。模型聚焦研究端影像数据的二分类任务，提供客观证据层，而非单独作为平台核心。 量表、认知测试和追踪数据不直接进入分类模型，而是作为综合报告的辅助解释依据。

B
两阶段
模型训练
Two-Phase Training
阶段一 · 自监督预训练
  • 目标：学习脑网络高阶表征
  • 属性重建任务：掩码节点特征 → 编码 → 解码 → MSE/SCE 损失
  • 对比学习任务：两组增强超图 → 边嵌入投影 → Wasserstein 相似度
  • 编码器：HGNNP 超图神经网络
  • 隐藏层维度：512
  • 训练轮数：150 epochs
  • 优化器：Adam · lr = 0.001
  • 损失权重：属性 λ=3 · 对比 λ=1
阶段二 · 下游分类微调
  • 目标：ADHD vs 对照组二分类
  • 特征提取：冻结编码器 → 节点嵌入展平为图级向量
  • 分类器：MLP（Linear → LeakyReLU → Linear）
  • 交叉验证：5-fold StratifiedKFold
  • 训练轮数：500 epochs
  • 优化器：Adam · lr = 0.1 · wd = 1e-4
  • 种子：ADHD seed=2020
训练完成 → 导出模型权重
