科研与演示平台的实际保护范围
保护选定业务内容与文件，限制身份信息与患者范围的访问，并保留可校验的历史记录。实际效果取决于部署、密钥管理与旧数据迁移；此说明不代表合规认证或临床验证。
🔐
隐私保护
Data Protection
Paillier 同态加密 — 对选定数值指标进行加密与聚合，统计范围以实际提取的字段为准。
AES-GCM 认证加密 — 保护敏感 JSON、文本、上传文件和私钥，兼顾内容保密与完整性校验。
独立密钥保管 — 主密钥由部署环境或独立文件提供，与数据库备份分开保存。
保护范围 — 服务端按授权解密业务内容；旧数据须完成迁移，传输还需部署 HTTPS。
🛡️
身份隔离
Identity Separation
审计患者代号 — DAC 审计页面使用伪名化代号，遮蔽姓名和联系方式。
按用途返回身份 — 已绑定且有权限的医生可在诊疗页面查看必要身份信息。
伪名化边界 — 身份与业务仍可由授权服务关联；患者代号不等同于彻底匿名化。
🔑
权限管控
Access Control
JWT 与密码哈希 — 使用 HS256 登录令牌和 bcrypt 密码哈希，令牌期限由部署配置决定。
角色检查 — 患者、研究人员与 DAC 的可执行操作按接口分别检查。
患者范围检查 — 诊疗访问检查医生绑定关系，审计访问检查 DAC 角色及患者分配。
关键访问留痕 — 记录关键读取、修改与拒绝访问，便于追查授权范围。
📋
可信存证
Record Verification
来源摘要 — 将原始内容摘要、版本与密文元数据绑定校验，发现覆盖内容不一致时明确提示。
历史版本保留 — 内容变化产生新版本，保留旧记录及关联审计结果。
同态统计审计 — 支持选定数值的时间或患者聚合；范围与提取规则保持一致。
真实性边界 — 校验能检查记录一致性，不能证明最初填写真实，也不能承诺检测任何改动。
