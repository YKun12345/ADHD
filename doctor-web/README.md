# 医生 / 研究人员 Web

这是 AB 合并版仍在使用的 Web 入口，患者主入口为 `miniprogram/` 微信小程序。

- 启动后端后访问：`http://127.0.0.1:8000/doctor-web/`
- 直接登录页：`http://127.0.0.1:8000/doctor-web/login.html`
- 页面资源位于本目录的 `css/`、`js/`，影像可视化资源来自仓库根目录的 `findviz/`。
- `reference/` 中是独立的安全和模型流程说明页，不是默认登录流程。

旧患者网页已完整保存在 `archive/legacy-patient-web/`，不参与默认启动，也不应作为患者端入口。
