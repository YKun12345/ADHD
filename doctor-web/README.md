# 医生 / 研究人员 Web

这是 AB 合并版的医生/研究人员 Web 入口。患者可使用 `patient-web/` 或 `miniprogram/` 微信小程序，两端共用后端账号。

- 启动后端后访问：`http://127.0.0.1:8000/doctor-web/`
- 直接登录页：`http://127.0.0.1:8000/doctor-web/login.html`
- 页面资源位于本目录的 `css/`、`js/`，影像可视化资源来自仓库根目录的 `findviz/`。
- `reference/` 中是独立的安全和模型流程说明页，不是默认登录流程。

历史患者网页完整保存在 `archive/legacy-patient-web/`，用于来源追溯。当前患者 Web 入口为 `/patient-web/`，归档目录不直接对外服务。

安全参考页说明选定数值 Paillier、敏感内容与文件 AES-GCM、审计患者代号、角色与患者范围检查，以及来源摘要与历史记录。保护范围须结合实际配置和旧数据迁移验收；该页面不构成合规认证。

影像页面需从后端服务的同源医生入口进入，并先选择已绑定患者。页面会申请短期患者影像会话；双击HTML或跨域预览时会提示需要同源访问。会话过期、绑定失效或切换到另一患者标签导致会话不匹配时，重新进入当前患者页面即可重新校验权限。
